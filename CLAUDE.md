# Instruksi untuk AI

**Sebelum mengerjakan tugas apa pun di repo ini:**

1. Baca [README.md](README.md).
2. Jalankan `claude plugin list` dan pastikan semua plugin yang diaktifkan di `.claude/settings.json` (`enabledPlugins`) berstatus enabled.
3. Jika ada yang belum terpasang, jalankan `bash scripts/setup-plugins.sh`, lalu beri tahu pengguna untuk me-restart Claude Code agar skill dan hook termuat.
4. Baru setelah itu lanjutkan tugas. Jangan melewati langkah ini.

Rencana proyek dan prompt UI ada di [todo.md](todo.md).
